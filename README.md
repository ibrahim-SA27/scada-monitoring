# Effluent Dashboard Replicator

Analyze the uploaded dashboard image and recreate it as closely as possible.

IMPORTANT:

The uploaded image is the design source of truth.

Do not redesign the dashboard.

Match the uploaded image layout exactly.

Build only the frontend UI for now.

Do NOT create backend, database, API, authentication, Gmail integration or ESP32 integration yet.

Requirements:

- Application name: EFFLUENT DASHBOARD

- Same dark navy/black industrial theme

- Same cyan/blue glowing borders

- Same left sidebar

- Same top status section

- Same industrial image section

- Same 5 sensor cards

- Same real-time sensor trend chart

- Same pollution risk analysis panel

- Same automatic discharge control panel

- Same spacing and visual hierarchy

- Same SCADA monitoring appearance

- Fully responsive desktop layout

Use mock data temporarily.

Focus entirely on visual accuracy.
